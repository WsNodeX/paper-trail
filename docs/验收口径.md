# PaperTrail 验收口径备忘

## 混合材料徽标：按元素查，不按关键词 match
矩阵/工作包的混合来源徽标文案为「N 篇示例 + M 篇导入 · 混在一起分析」，
其中**不含「混合材料」四字**，用 `/混合材料/` 去 match `document.body` 必然 false。

正确验收（两个元素同时存在才算通过）：
```js
document.querySelector('.matrix-count').innerText   // "9 / 9 篇"
document.querySelector('.mixed-hint').innerText      // "6 篇示例 + 3 篇导入 · 混在一起分析"
```

## 触控命中区：宽度断点而非设备指针
命中区外扩使用 `@media (max-width: 820px)`，**不要**再用 `@media (pointer: coarse)`——
桌面浏览器主指针是 mouse（coarse=false），DevTools 手机模拟亦不命中，该媒体查询等于失效。
`.tabs` 为 `overflow:auto` 横滚容器，会在纵向裁掉 tab 的外扩伪元素；故在窄屏给
`.tabs` 补 `padding:8px 0; margin:-8px 0`（净高度不变）以留出裁剪余量。
`.chip / .src-chip` 用真尺寸放大（30px，`!important` 覆盖内联），不要再叠伪元素外扩，避免互相遮挡。
