================================================================
第 0 步｜把失效证据先复现出来（改之前必须看到红色）
================================================================
现状：web/assets/style.css:749-755
    /* 稀疏按钮用伪元素外扩命中区（仅触屏） */
    @media (pointer: coarse) {
      .tab, .btn-sm, .rel-expand, .rel-expand button { position: relative; }
      .tab::after, .btn-sm::after, .rel-expand::after, .rel-expand button::after {
        content: ""; position: absolute; inset: -8px -6px; min-width: 44px; min-height: 44px;
      }
    }

问题：pointer: coarse 只匹配「主输入设备是手指」的设备。
电脑浏览器（哪怕窗口拉到 700px 宽）、Windows 触屏笔记本、
Chrome DevTools 的手机模拟，主指针都是 mouse → 命中 false。
实测三档宽度（1440 / 820 / 700）下：
    matchMedia('(pointer: coarse)') === false
    .tab 高度 40px、::after 的 content === "none"、min-height 0px
    .btn-sm 高度 36px、::after 同样为空
也就是说这段 CSS 从来没生效过，等于上一轮第 1 步的「稀疏按钮外扩」
白写了，五个 tab、六个「返回首页」、展开/收起、重置筛选仍然是 36–40px。

复现步骤（在浏览器控制台跑，把输出贴回来）：
    matchMedia('(pointer: coarse)').matches      // 桌面：false
    matchMedia('(any-pointer: coarse)').matches  // 桌面触屏本：true
    getComputedStyle(document.querySelector('.tab'), '::after').content  // "none"

================================================================
第 1 步｜把触屏判断改成宽度断点
================================================================
理由：我们真正想覆盖的是「屏幕窄 = 很可能在用手点」，
而不是「这台机器的主指针是不是手指」。宽度断点不依赖设备探测，
桌面拉窄窗口、DevTools 模拟、真机预览三种场景全都命中。

把 style.css:749-755 整段替换为：

    /* 窄屏下把小按钮的命中区撑到 44×44（不依赖设备指针类型） */
    @media (max-width: 820px) {
      .tab, .btn-sm, .rel-expand, .rel-expand button { position: relative; }
      .tab::after, .btn-sm::after, .rel-expand::after, .rel-expand button::after {
        content: ""; position: absolute; inset: -8px -6px;
        min-width: 44px; min-height: 44px;
      }
    }

注意三点（都是踩过的坑）：
  1. 伪元素会盖住相邻元素，所以外扩只给稀疏按钮用。
     已经放大到 30px 的 .chip / .src-chip 不要再加伪元素，
     它们走的是上面 744-748 行的真放大，两套规则不要混。
  2. .rel-expand 本身是容器，给它 position: relative 会让里面的
     button 的 ::after 以容器为参照，可能撑出空白块。
     改成只给 button 加，.rel-expand 那一份删掉：
        @media (max-width: 820px) {
          .tab, .btn-sm, .rel-expand button { position: relative; }
          .tab::after, .btn-sm::after, .rel-expand button::after {
            content: ""; position: absolute; inset: -8px -6px;
            min-width: 44px; min-height: 44px;
          }
        }
  3. 顶层 .tabs 是 overflow-x: auto 的横滚容器，伪元素超出左边缘时
     会被裁掉。所以第一个 tab 的左外扩要收回：
        .tabs .tab:first-child::after { left: 0; }

第 2 步｜改完立刻验（三条自查，数字贴回来）
================================================================
在 700px 宽窗口（桌面浏览器，不是手机模拟）下控制台执行：

    getComputedStyle(document.querySelector('.tab'), '::after').content
      → 期望 ""

    (() => { const t = document.querySelector('.tab'); const r = t.getBoundingClientRect();
             const e = document.elementFromPoint(r.left + r.width/2, r.top - 6);
             return e === t || t.contains(e); })()
      → 期望 true（说明向上 6px 仍命中同一个 tab）

    (() => { const b = document.querySelector('.btn-sm'); const r = b.getBoundingClientRect();
             const e = document.elementFromPoint(r.left + r.width/2, r.top - 6);
             return e === b || b.contains(e); })()
      → 期望 true

1440px 宽下再跑一次同两条 elementFromPoint，期望 false 或 null
（桌面大屏不该有外扩，避免误触旁边的元素）。
